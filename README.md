# the machine — a field study

An animated, scrolling field study of an imaginary factory: intake, sorters,
crushers, painters, a skyway and a ferris wheel, all running on a small
hand-rolled physics simulation and rendered to canvas.

**[▶ Live demo](https://bohemian-miser.github.io/the_machine/)**

## Running locally

Any static file server works — the page is plain ES modules:

```
npx serve .
```

## Tests

```
npm run test:unit
npm run test:e2e
```
